# Thessley product deck

`thessley.html` — a self-contained 13-slide deck (no external assets, no CDN).

- Open it in a browser, or serve the folder: `python3 -m http.server -d presentations 8000`
- Keys: **←/→**, **Space**, **Home/End**; click the left/right third of the screen; `#7` deep-links a slide.
- Print to PDF: `google-chrome --headless --no-pdf-header-footer --print-to-pdf=thessley.pdf presentations/thessley.html` (already exported as `thessley.pdf`, 13 pages).
- Palette and type follow the product UI: violet/teal on near-black, system sans, tabular numerals.

Slides: title · problem · idea · architecture · flow · security model · WordPress · devices · Linux PAM · Windows/AD · hardening · operations · close.
